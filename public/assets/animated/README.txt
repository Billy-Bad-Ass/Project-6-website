BBA NETWORK — ANIMATED LOGO
===========================

SVG (animated, transparent background, infinitely scalable)
  bba-logo-animated-ambient-for-dark.svg    10s loop, for dark backgrounds  <- Jarvis dashboard
  bba-logo-animated-active-for-dark.svg     3.6s loop, for dark backgrounds
  bba-logo-animated-ambient-for-light.svg   10s loop, for light backgrounds
  bba-logo-animated-active-for-light.svg    3.6s loop, for light backgrounds

  Use in a web page or dashboard:
    <img src="bba-logo-animated-ambient-for-dark.svg" width="320">
  Or inline the file's contents directly into your HTML.
  Note: animation runs in browsers. It will not animate in image editors
  or when embedded in email (use the static PNGs from the logo kit there).

HTML (self-contained, opens straight in a browser, nothing to install)
  bba-animated-logo-ambient.html   full-screen mark on #0B0F16, 10s loop
  bba-animated-logo-active.html    full-screen mark on #0B0F16, 3.6s loop

  Drop either into a dashboard iframe:
    <iframe src="bba-animated-logo-ambient.html" style="border:0;width:100%;height:100%"></iframe>
